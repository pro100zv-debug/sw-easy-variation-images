- EN: Nothing changes until you press a button. One "Apply" button per value (only those variations change), choice between replacing all or only empty ones, "Undo" for the last change. New variations get images only in products where the panel was used. Additional images use the native WooCommerce 11.1+ variation gallery (used by WoodMart 8.6+).
- ES: No cambia nada hasta pulsar un botón. Un botón «Aplicar» por valor (solo cambian esas variaciones), elegir entre sustituir todas o solo las vacías, «Deshacer» el último cambio. Las variaciones nuevas reciben imágenes solo en productos donde se usó el panel. Las imágenes adicionales usan la galería de variaciones nativa de WooCommerce 11.1+ (la que usa WoodMart 8.6+).
